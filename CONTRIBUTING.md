# Участие в разработке

Спасибо, что хотите помочь! Проект маленький, поэтому правил немного.

## Окружение

Нужен Node.js 24 (`.nvmrc`).

```bash
npm install     # заодно ставит git-хуки
npm run setup   # скачивает остановки и расписание
npm run dev
```

## Инструменты

| Команда                 | Что делает                                        |
| ----------------------- | ------------------------------------------------- |
| `npm run check`         | линтер, форматирование, типы и тесты, как в CI    |
| `npm run fix`           | автоматически исправляет форматирование и импорты |
| `npm run lint`          | только линтер                                     |
| `npm run typecheck`     | только проверка типов                             |
| `npm test`              | тесты (встроенный `node:test`)                    |
| `npm run test:coverage` | тесты с покрытием                                 |

- Форматирование, линтер и сортировку импортов делает [Biome](https://biomejs.dev), настройки в `biome.json`. Стиль обсуждать не нужно: его задаёт форматтер.
- Перед коммитом автоматически запускается Biome для изменённых файлов (`simple-git-hooks` и `lint-staged`). Если хук мешает, один раз можно пропустить его через `SKIP_SIMPLE_GIT_HOOKS=1`, но CI всё равно проверит.
- `git blame` лучше настроить так, чтобы он пропускал коммит с массовым форматированием: `git config blame.ignoreRevsFile .git-blame-ignore-revs`.
- Зависимости обновляет Dependabot раз в неделю.

## Pull request

1. Сделайте ветку от `main`.
2. Добавьте или обновите тесты для изменений в логике (`src/*.test.ts`).
3. Убедитесь, что `npm run check` и `npm run build` проходят.
4. Опишите в PR, что и зачем меняется. Для изменений интерфейса приложите скриншот.
